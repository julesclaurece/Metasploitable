    Résultat : accès utilisateur daemon — diagnostic ACL requis

  • TikiWiki 1.9.5 — RCE tiki-graph_formula.php (CVE-2007-5423) MS1 · port 80
    Résultat : reverse shell www-data (contournement de 2 filtres)

  • NetBIOS Name Service MS1 · port 137/udp

  • MySQL 5.0.51a — Identifiants par défaut + privilège FILE MS1 · port 3306
    Résultat : root base + lecture/écriture arbitraire de fichiers

  • SMTP Postfix — Énumération d'utilisateurs (VRFY) MS1 · port 25
    Résultat : 35 comptes confirmés, recoupement avec Samba
  • UnrealIRCd 3.2.8.1 — Backdoor (CVE-2010-2075) MS2 · port 6667
    Résultat : accès root (shell de commande, payload perl)
  • distccd — Exécution de commande (CVE-2004-2687) MS2 · port 3632

Méthodologie commune

Chaque service est testé selon la même démarche : reconnaissance (identification du service et de sa version via nmap), recherche de vulnérabilité (CVE associée), tentative d'exploitation manuelle quand c'est pertinent, exploitation outillée (Metasploit), puis vérification de l'accès obtenu. Le détail technique brut (commandes exactes, troubleshooting) est consigné dans les write-ups du dépôt, classés par VM et par rédacteur (ms1/<jules|josa>/, ms2/<jules|josa>/, ms3/<jules|josa>/) ; ce rapport en reprend la synthèse pédagogique avec captures à l'appui.
