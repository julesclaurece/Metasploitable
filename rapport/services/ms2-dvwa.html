DVWA — injection de commande

Entrée utilisateur passée au shell sans filtrage → exécution de commande (RCE)

Service / PortDVWA (application web) — port 80, /dvwa/
CibleMetasploitable 2 — 192.168.56.101
ClasseInjection de commande (OWASP — Command Injection)
RésultatRCE www-data via la page Command Execution
Testé parZANNOU Josaphat

1. Identification / accès

DVWA (Damn Vulnerable Web Application) est une application volontairement vulnérable, listée sur la page d'accueil du serveur. On s'y connecte avec les identifiants par défaut admin:password. Sa page Command Execution propose de « pinger » une adresse IP : l'entrée est passée telle quelle à un shell_exec( "ping -c 4 $ip") côté serveur, sans filtrage au niveau de sécurité low.

2. Démarche d'exploitation — injection de commande

Niveau de sécurité réglé sur low (PHPIDS: disabled). Le formulaire a un champ ip ; on y injecte une commande à la suite de l'IP avec le séparateur ; :

Champ « ping » : 127.0.0.1;id;uname -a;hostname

Résultat affiché sous le formulaire :
PING 127.0.0.1 (127.0.0.1) 56(84) bytes of data.
uid=33(www-data) gid=33(www-data) groups=33(www-data)
Linux metasploitable 2.6.24-16-server #1 SMP Thu Apr 10 13:58:00 UTC 2008 i686 GNU/Linux
metasploitable
Le ping s'exécute, puis la commande injectée (id;uname -a;hostname) s'exécute à la suite — exécution de commande arbitraire côté serveur, en tant que www-data.

Détail technique — le bouton d'envoi du formulaire s'appelle submit (minuscule) : côté serveur le code teste isset($_POST['submit']). Envoyer Submit (majuscule) ne déclenche pas le traitement et renvoie le formulaire vide.

3. Preuve d'accès obtenu

La réponse de la page contient uid=33(www-data) : la commande injectée s'exécute avec les droits du serveur web. À partir de là, on peut enchaîner vers un reverse shell interactif ou chercher une élévation de privilèges.

4. Remédiation

RECOMMANDATIONS
  • Ne jamais concaténer une entrée utilisateur dans une commande shell ; utiliser des API sûres et escapeshellarg()/escapeshellcmd().
  • Valider strictement le format attendu (ici une adresse IP) par liste blanche / expression régulière.
  • Appliquer le principe du moindre privilège au compte du serveur web et isoler l'application.
  • DVWA est une cible d'entraînement : en production, un tel code ne doit jamais être déployé.
